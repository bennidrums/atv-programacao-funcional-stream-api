# Atividade EBAC — Stream API

Este projeto foi desenvolvido como parte dos estudos de Java Back-end na EBAC, com o objetivo de praticar o uso da Stream API em situações simples.

## O que foi feito

- Filtrar funcionários de acordo com a data de nascimento e o salário.
- Somar os números pares de uma lista.
- Encontrar os maiores salários entre funcionários CLT com menos de 25 anos.

## Conceitos praticados

- Stream API
- Expressões lambda
- `filter()`, `flatMap()`, `sorted()` e `limit()`
- Listas e classes em Java
- Manipulação de datas com `LocalDate`

## Estrutura do projeto

- `Main.java`: contém os exercícios e os dados utilizados nos testes.
- `Empresa.java`: representa uma empresa e seus funcionários.
- `Funcionario.java`: representa um funcionário.

## Como executar

O projeto pode ser executado em uma IDE Java, como o IntelliJ IDEA, utilizando a classe `Main`.
